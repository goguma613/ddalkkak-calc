# 딸깍 계산기

인터넷 · 전화 상품의 딸깍 금액을 계산하는 단일 페이지 웹 도구.

## 계산 규칙

```
인터넷 = ( 수수료 − 공제액 ) × ( 1 − 차감율 )     기본: 공제 55,000원 / 차감 20·17·15%
전화   = 수수료 × ( 1 − 전화 차감율 )             기본: 50%, 공제 없음
```

## 데이터 보호

상품·수수료 데이터는 `data.js` 에 **AES-256-GCM** 으로 암호화되어 들어 있습니다.
키는 비밀번호에서 PBKDF2-SHA256(600,000회)으로 유도합니다.
비밀번호를 모르면 저장소나 개발자 도구에서도 내용을 알 수 없습니다.

> 잠금을 해제한 브라우저에서는 데이터가 복호화된 상태로 보입니다.
> 정적 사이트의 구조상 이는 피할 수 없으며, 비밀번호를 아는 사용자에게만 해당됩니다.

## 데이터 변경

1. 로컬에서 `make-data.html` 을 엽니다. (저장소에 포함되지 않음)
2. 비밀번호와 데이터를 넣고 `data.js` 를 생성해 이 폴더에 덮어씁니다.
3. 커밋 후 푸시하면 배포됩니다.

계산기 화면의 **내보내기** 로 현재 데이터를 JSON 으로 받아 2번 단계에 붙여넣을 수 있습니다.

## 사용

- 잠금 해제는 기기별로 한 번. 이후 브라우저에 저장되어 바로 열립니다.
- **🔒 잠금** 을 누르면 그 기기의 저장 데이터를 지우고 다시 잠급니다.
- **원본 복구** 는 직접 수정한 내용을 버리고 배포된 데이터로 되돌립니다.
