# 딸깍 계산기

인터넷 · 전화 · TV 상품의 딸깍 금액과 마진을 계산하는 단일 페이지 웹 도구.

## 상품군

상단 탭으로 전환하며, 고른 상품군만 표와 묶음 계산에 나온다.
전화는 정책이 같아 양쪽 공용이고, BTV 는 오피스넷에서만 고를 수 있다.

| | 소호인터넷 | 오피스넷 (비즈광랜) |
|---|---|---|
| 인터넷 | 100M / 500M / 1G | 100M / 500M / 1G · 단독 · 고센 결합 |
| 전화 | 공용 | 공용 |
| TV | 인터넷 상품에 포함 | BTV · 대수 선택 |
| 유심 | UIT 결합 · 단독/번들 | — |

## 계산 규칙

```
소호 인터넷 = ( 수수료 − 플랫폼 공제 ) × ( 1 − 차감율 )     기본: 55,000 / 20·17·15%
오피스넷    = ( 오피스넷 + BTV 수수료 합계 ) − 플랫폼 공제 − 우리 마진
                                                          기본: 55,000 / 50,000
전화        = 수수료 × ( 1 − 전화 차감율 )                 기본: 50%, 공제 없음
유심        = 수수료 × ( 1 − 유심 차감율 )                 기본: 30%, 공제 없음
```

- 플랫폼 공제는 타 플랫폼이 가져가는 몫이라 마진에 잡지 않는다.
- 오피스넷은 공제와 마진을 묶음 전체에 한 번씩만 적용한다. 그래서 BTV 수수료는
  딸깍에 그대로 더해지고, BTV 자체의 마진은 0 이다.
- 유심은 수수료가 단독·번들로 나뉜다. 묶음 계산에서 인터넷을 함께 고르면 번들
  수수료를 자동으로 적용하고, 유심만 고르면 단독 수수료를 쓴다.
  요금제 기준에 미달하는 구간은 수수료 0 으로 두어 «미지급» 으로 표시된다.
- 딸깍 금액은 절사 단위(기본 10,000원)로 내리고, 절사된 잔액은 마진에 포함된다.
- 모든 기준값은 «계산 설정» 에서 바꿀 수 있다.

## 데이터 보호

상품·수수료 데이터는 `data.js` 에 **AES-256-GCM** 으로 암호화되어 들어 있다.
키는 비밀번호에서 PBKDF2-SHA256(600,000회)으로 유도한다.
비밀번호를 모르면 저장소나 개발자 도구에서도 내용을 알 수 없다.

> 잠금을 해제한 브라우저에서는 데이터가 복호화된 상태로 보인다.
> 정적 사이트의 구조상 이는 피할 수 없으며, 비밀번호를 아는 사용자에게만 해당된다.

## 데이터 변경

1. 계산기의 **내보내기** 로 현재 데이터를 JSON 으로 받는다. (고친 내용이 없으면 생략)
2. 로컬에서 `make-data.html` 을 연다. (평문 데이터가 들어 있어 저장소에 포함되지 않음)
3. 1번 JSON 을 붙여넣고 비밀번호를 넣어 `data.js` 를 생성해 이 폴더에 덮어쓴다.
4. 커밋 후 푸시하면 배포된다.

배포된 `data.js` 가 바뀌면 각 기기가 지문을 비교해 알아서 감지하고,
비밀번호를 받아 새 데이터를 불러온다. 직접 고친 내용을 지키려면
잠금 화면의 **기존 데이터 그대로 쓰기** 로 넘어가면 된다.

## 사용

- 잠금 해제는 기기별로 한 번. 이후 브라우저에 저장되어 바로 열린다.
- 금액을 누르면 «292,000» 형식으로 클립보드에 복사된다.
- **🔒 잠금** 은 그 기기의 저장 데이터를 지우고 다시 잠근다.
- **원본 복구** 는 직접 고친 내용을 버리고 배포된 데이터로 되돌린다.
